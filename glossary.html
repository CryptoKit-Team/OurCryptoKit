Cryptography Glossary

Alphabetical reference of cryptographic terms and definitions.

AES (Advanced Encryption Standard)
Symmetric block cipher adopted by the U.S. government. Available in 128, 192, and 256-bit key sizes.
Asymmetric Encryption
Encryption using a pair of keys (public and private). Also called public-key cryptography.
Cipher
An algorithm used for encryption or decryption.
Ciphertext
The encrypted output of a plaintext message.
Digest
The output of a hash function; a fixed-size fingerprint of input data.
ECC (Elliptic Curve Cryptography)
Public-key cryptography based on elliptic curves. Offers strong security with smaller key sizes than RSA.
ECDSA
Elliptic Curve Digital Signature Algorithm — a signature algorithm using ECC.
Entropy
A measure of randomness or unpredictability. Higher entropy = stronger security.
Hash Collision
When two different inputs produce the same hash output. Breaks hash security.
Hash Function
A one-way function that maps data of any size to a fixed-size output.
HMAC
Hash-based Message Authentication Code — combines a hash with a secret key for authentication.
IV (Initialization Vector)
A random value used in block cipher modes to ensure unique ciphertexts.
KDF (Key Derivation Function)
Derives cryptographic keys from a password or secret. Examples: PBKDF2, Argon2.
Key Pair
A pair of related keys (public and private) used in asymmetric cryptography.
Nonce
Number used once — a random value used only once in a cryptographic operation.
PEM (Privacy Enhanced Mail)
A common text-based format for storing cryptographic keys and certificates.
Plaintext
Unencrypted, readable data before encryption or after decryption.
Private Key
The secret half of an asymmetric key pair. Must never be shared.
Public Key
The shareable half of an asymmetric key pair. Used to encrypt data for the owner or verify signatures.
Rainbow Table
A precomputed table of hashes used to reverse hash functions. Defeated by salt.
RSA
An asymmetric encryption algorithm based on the difficulty of factoring large primes.
Salt
Random data added to a password before hashing to prevent rainbow table attacks.
SHA (Secure Hash Algorithm)
A family of cryptographic hash functions. SHA-256 and SHA-512 are widely used.
Symmetric Encryption
Encryption using the same key for both encryption and decryption.
TLS (Transport Layer Security)
Cryptographic protocol securing communication over networks (successor to SSL).
