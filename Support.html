Frequently Asked Questions

Filter by category or use the search bar above

What is CryptoKit?
+

CryptoKit is a complete cryptography platform offering encryption & decryption tools, hash generators, digital signature utilities, key management, certificate analysis, and educational resources — built for developers, security researchers, students, and enterprises.

Which cryptographic algorithms are supported?
+

Symmetric: AES-128/192/256 ChaCha20-Poly1305 3DES Blowfish Camellia

Asymmetric: RSA-2048/4096 ECDSA Ed25519 X25519

Hashing: SHA-256/384/512 SHA-3 BLAKE2b Argon2id MD5 (legacy only)

Is my data processed securely?
+

Absolutely. The majority of cryptographic operations run entirely client-side in your browser using the Web Crypto API. Your plaintext, keys, and passwords never leave your device.

For server-side API operations, all traffic is protected by TLS 1.3, processed in memory only, and never written to persistent storage or logs.

Can you recover my lost encryption key?
+

No — and that's by design. CryptoKit uses a zero-knowledge architecture. We never receive or store your encryption keys, so we physically cannot recover them. Always back up your keys in a secure password manager or hardware token.

How do I create an account?
+

Click Sign Up on the homepage. You can register with an email address or via OAuth (Google / GitHub). We strongly recommend enabling Two-Factor Authentication immediately after registration.

How do I reset my password?
+

On the login page click Forgot Password, enter your registered email, and we'll send a secure reset link that expires in 60 minutes. If 2FA is enabled you'll also need a code from your authenticator app.

How do I delete my account and data?
+

Go to Dashboard → Settings → Danger Zone → Delete Account. You'll be able to export all your data first. Everything is permanently purged from our systems within 30 days, in line with GDPR requirements.

How do I get an API key?
+

Head to Dashboard → Settings → API Keys and generate a key with scoped permissions. Free tier accounts get 100 requests/hour. Never expose your key in client-side JavaScript or public repositories.

What happens if I exceed API rate limits?
+

You'll receive a 429 Too Many Requests response. The X-RateLimit-Reset header tells you when your quota refreshes. Implement exponential backoff, or upgrade to Pro / Enterprise for higher limits.

What pricing plans are available?
+

Free — Core tools, 100 API calls/hr, community support

Pro ($19/mo) — All tools, 1,000 API calls/hr, priority support, batch processing

Enterprise (Custom) — Unlimited calls, SLA, dedicated engineer, on-prem option

Annual billing saves you 20%.

What is your refund policy?
+

Annual plans come with a 14-day money-back guarantee. Monthly plans can be cancelled anytime and you keep access until the end of your billing cycle. Email billing@cryptokit.com for refunds.

Is CryptoKit open source?
+

Our core cryptographic libraries are fully open source on GitHub for community audit and transparency. The web platform itself is proprietary, but all algorithm implementations and security practices are published for peer review. Contributions and responsible disclosures are always welcome.
