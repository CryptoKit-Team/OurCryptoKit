💻 Terminal

Terminal Mode

Interactive command-line interface for power users and developers.

📑 On This Page

    Introduction

    Terminal Mode provides a CLI-like experience for all CryptoKit tools. Perfect for developers who prefer keyboard-driven workflows.

    💡
    Access
    Click the "💻 Terminal" button in the top navigation to launch.

    Available Commands

    Hash Command

    Terminal 
    cryptokit hash --algo <algorithm> --input <text>

Options:
  --algo    Algorithm: MD5, SHA-1, SHA-256, SHA-512
  --input   Text to hash
  --file    File path (alternative to --input)

Example:
  cryptokit hash --algo SHA-256 --input "Hello World"

    Encrypt Command

    Terminal 
    cryptokit encrypt --algo <algorithm> --key <key> --input <text>

Options:
  --algo    Algorithm: AES-256, RSA
  --key     Encryption key
  --input   Text to encrypt
  --output  Output file (optional)

Example:
  cryptokit encrypt --algo AES-256 --key mysecret --input "secret message"

    Decrypt Command

    Terminal 
    cryptokit decrypt --algo <algorithm> --key <key> --input <ciphertext>

Example:
  cryptokit decrypt --algo AES-256 --key mysecret --input "..."

    RSA Command

    Terminal 
    cryptokit rsa generate --size <bits>

Options:
  --size    Key size: 1024, 2048, 4096
  --export  Format: PEM, DER

Example:
  cryptokit rsa generate --size 2048 --export PEM

    Password Command

    Terminal 
    cryptokit password generate --length <num> [options]

Options:
  --length     Password length (8-64)
  --symbols    Include symbols (default: true)
  --numbers    Include numbers (default: true)
  --uppercase  Include uppercase (default: true)

Example:
  cryptokit password generate --length 20 --symbols

    Keyboard Shortcuts

    ShortcutAction
    ↑Previous command
    ↓Next command
    TabAuto-complete
    Ctrl + LClear screen
    Ctrl + CCancel command
    Ctrl + KSearch history

    Command Chaining

    You can pipe commands together for complex operations:

    Terminal 
    # Hash and encode
cryptokit hash --algo SHA-256 --input "text" | cryptokit encode --format base64

# Generate password and hash it
cryptokit password generate --length 32 | cryptokit hash --algo SHA-256
