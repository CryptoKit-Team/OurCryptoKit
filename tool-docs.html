    🔑 RSA Key Generator

    Generate secure RSA public/private key pairs for encryption and digital signatures.

    When to Use

    • RSA-2048: Standard security, faster generation (recommended for most uses)
    • RSA-4096: Maximum security, slower generation (for long-term secrets)

    How to Use

    1. Visit the RSA Key Generator
    2. Select key size (2048 or 4096 bits)
    3. Click "Generate Keys"
    4. Copy or download your public and private keys in PEM format
    🔒
    Never Share Your Private Key
    The private key must be kept secret at all times. Only share the public key.

    Code Example

    JavaScript 
    const keyPair = await crypto.subtle.generateKey(
    {
        name: "RSA-OAEP",
        modulusLength: 2048,
        publicExponent: new Uint8Array([1, 0, 1]),
        hash: "SHA-256"
    },
    true,
    ["encrypt", "decrypt"]
);

    📄 File Integrity Checker

    Verify that a file hasn't been tampered with by comparing its cryptographic hash.

    How to Use

    1. Upload the file you want to check
    2. Select the hash algorithm (SHA-256 recommended)
    3. Compare the generated hash with the expected hash
    4. If they match → file is intact ✅
    5. If they don't → file has been modified ❌
    ⚠️
    MD5 is Deprecated
    Never use MD5 for security-critical integrity checks. Use SHA-256 or SHA-512 instead.

    🔐 Text Encrypt / Decrypt

    Encrypt and decrypt text messages using AES-256 or RSA.

    AES-256 vs RSA

    • AES-256: Use for encrypting messages of any size. Requires a shared secret key.
    • RSA: Use for encrypting small amounts of data or exchanging AES keys securely.
    💡
    Best Practice
    For large data, use AES for encryption and RSA to protect the AES key (hybrid encryption).

    ✍️ Digital Signature

    Sign documents to prove authenticity and detect tampering.

    Sign & Verify Workflow

    1. Signing: Use your private key to create a signature for the document
    2. Verifying: Others use your public key to verify the signature

    Entropy Explained

    Entropy measures password strength. Higher = more secure. Formula:

    Formula 
    Entropy (bits) = log2(pool_size^length)

Example:
16 chars from 94 possible = log2(94^16) = ~105 bits
