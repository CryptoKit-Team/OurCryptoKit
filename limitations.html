Known Limitations

Important limitations and warnings to be aware of when using CryptoKit.

📑 On This Page

    Browser API Limitations

    CryptoKit relies on the Web Crypto API, which has some inherent limitations:

    • Not all algorithms are supported in all browsers
    • Requires HTTPS or localhost to function
    • Some operations are async-only
    • No direct access to hardware security modules

    File Size Limits

    Browser memory constrains file operations:

    OperationRecommended MaxAbsolute Max
    Hash generation100 MB500 MB
    Encryption50 MB200 MB
    Signing20 MB100 MB

    Not Suitable For

    🚫
    Do Not Use For
    • Military or government-grade classified data
    • Life-critical medical systems
    • Financial systems requiring FIPS compliance
    • Applications requiring audited implementations
    • Long-term storage without additional security layers

    Unsupported Algorithms

    The following algorithms are NOT available:

    • Post-quantum algorithms (coming soon)
    • Homomorphic encryption
    • Zero-knowledge proofs
    • Custom or proprietary algorithms
    • Quantum key distribution

    Professional Audits Recommended

    ⚠️
    Important
    For any critical application, we strongly recommend hiring professional cryptography auditors and using certified libraries.
