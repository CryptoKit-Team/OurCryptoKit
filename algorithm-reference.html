    Quick Recommendations

    ✅
    Use These
    AES-256, RSA-2048+, SHA-256+, ECC P-256, Argon2, BLAKE2/3
    ❌
    Avoid These
    MD5, SHA-1, DES, 3DES, RSA-1024, plain SHA for passwords
