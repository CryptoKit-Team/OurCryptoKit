OAEP padding lab

RSA-OAEP is the modern, secure padding scheme for encryption. Choose a hash and see exactly how much it eats into your usable message size.

Why not PKCS#1 v1.5 for encryption? It's vulnerable to padding-oracle attacks (the Bleichenbacher attack, 1998) where an attacker who can observe padding-valid/invalid errors can decrypt ciphertexts without the private key. OAEP is provably secure against this class of attack, so browsers only expose it for RSA encryption.

Compare signature schemes

RSASSA-PKCS1-v1_5 is deterministic and simple; RSA-PSS adds randomized salting and is the scheme recommended for new systems. Sign the same message with both and compare.

Notice: sign the same message twice with PSS and you'll get a different signature each time (random salt) — but both still verify. PKCS1-v1_5 always produces the exact same signature for the same message and key.

Why key size matters: factor a small N yourself

RSA's security rests entirely on how hard it is to factor n = p × q back into its two primes. This demo factors tiny numbers in your browser (Pollard's rho) — real RSA moduli have 600+ digits, far beyond what any computer on Earth can factor.
