Some systems authenticate messages with MAC = Hash(secret ‖ message). For Merkle–Damgård hashes like MD5/SHA-1/SHA-256, knowing only the MAC and the message length lets an attacker compute a valid MAC for message ‖ glue-padding ‖ extra-data — without ever learning the secret.

Remediation Use HMAC (e.g. HMAC-SHA256) instead of Hash(secret‖message) — HMAC's nested construction is immune to length-extension. Or use a hash from the SHA-3 family, which is not Merkle–Damgård based.
Stream-cipher modes like CTR produce ciphertext by XOR-ing plaintext with a keystream. Flip a bit in the ciphertext and the corresponding bit in the decrypted plaintext flips too — with no integrity check, an attacker can edit encrypted data without knowing the key.
